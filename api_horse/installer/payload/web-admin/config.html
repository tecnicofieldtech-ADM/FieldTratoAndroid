Espelho BI (next-api)

      
Eventos GET/POST da API Horse são enviados para a next-api, que grava no PostgreSQL.

      

        
        
      

      

        
        
        
A API Horse usa a porta 3001. A next-api deve rodar em outra porta (ex.: 3000).

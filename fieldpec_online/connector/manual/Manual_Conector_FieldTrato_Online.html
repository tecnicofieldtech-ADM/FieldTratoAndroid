Manual do Conector

Guia passo a passo para instalar o conector na máquina do escritório, ligar o banco FieldPec (Firebird) à nuvem e subir / baixar os dados usados pelo app FieldTrato.

Versão: 1.0 Painel: http://127.0.0.1:3080 Público: cliente / TI local

01 · Visão geral

Como funciona

O conector roda no PC do cliente (onde está o Firebird do FieldPec). Ele fala com a API na nuvem (AWS). O tablet FieldTrato usa a mesma API — sem precisar do Delphi Horse no escritório.

FieldPec Firebird (.FDB)
→
Conector Painel :3080
→
API AWS + FieldTrato
Aba Para que serve
Subir / Baixar Enviar cadastros/previsão à nuvem e puxar fabricação/fornecimento do tablet para o Field.
Acompanhar Ver o que está pendente na nuvem e o que já foi gravado no Field.
Configuração URL da API, código do cliente, caminho do .FDB e opções de gravação.
Status Último resultado da sincronização nesta sessão.
02 · Instalação

Instalar o conector

Prefira o instalador FieldPec-Conector-Setup-….exe. Execute como Administrador.

1

Receba o instalador

Arquivo enviado pela RS Sistemas, por exemplo FieldPec-Conector-Setup-1.0.0.exe.

2

Execute como Administrador

Clique com o botão direito → Executar como administrador. Aceite a instalação em C:\FieldPecConnector.

3

Aguarde o pós-instalação

O setup instala Node.js se necessário, registra o serviço Windows FieldPecOnlineConnector e inicia o painel no navegador.

4

Abra o painel

Endereço: http://127.0.0.1:3080 (também disponível pelo Menu Iniciar).

Alternativa via ZIP Extraia o pacote, clique com o direito em INSTALAR.cmd → Executar como administrador. O resultado é o mesmo serviço + painel.
Requisito O Firebird do FieldPec precisa estar acessível nesta máquina (serviço Firebird ativo e arquivo .FDB no caminho correto). Em muitos ambientes é necessário o cliente Firebird (fbclient.dll).
03 · Configuração

Configurar API e banco

Vá na aba Configuração, preencha os campos abaixo e clique em Salvar. Os valores exatos (URL, código do cliente e caminho do .FDB) são fornecidos pela RS Sistemas / TI da fazenda.

API na AWS

CampoO que preencher
CLOUD_API_URL Endereço da API, ex.: http://SEU_IP:3111 (informado pela RS).
CLIENT_CODE Código único do cliente (mesmo usado no FieldTrato). Obrigatório.
ADMIN_TOKEN Em geral open, salvo orientação diferente.

Banco FieldPec (Firebird)

CampoO que preencher
SOURCE_MODE firebird (recomendado) — lê/grava direto no .FDB.
ID_FAZENDA ID da fazenda no FieldPec (ex.: 1).
FB_HOST / FB_PORT Normalmente 127.0.0.1 e 3050.
FB_DATABASE Caminho completo do arquivo .FDB nesta máquina.
FB_USER / FB_PASSWORD Usuário e senha Firebird (ex.: SYSDBA).

Opções importantes

CampoRecomendação
REPLAY_TO_LOCAL Use 1 — gravar no Firebird para que o Baixar grave fabricação/fornecimento no Field.
SYNC_INTERVAL_SEC 0 = só manual (botões). Intervalo em segundos se quiser automático.
CONNECTOR_PORT Padrão 3080. Se alterar, reinicie o serviço.
Depois de salvar Se mudar a porta do conector, reinicie o serviço FieldPecOnlineConnector (serviços do Windows) e reabra o painel.
04 · Validação

Testar conexões

Antes de subir ou baixar dados, confirme que o Firebird e a API respondem.

1

Abra a aba Subir / Baixar

No topo do painel, selecione Subir / Baixar.

2

Clique em “Testar conexões”

O resultado aparece na área Pronto / log, em linguagem simples. Corrija Configuração se Firebird ou API falharem.

05 · Subir

Subir dados do Field para a nuvem

Envia cadastros e previsão do FieldPec (Firebird) para a API — fazendas, usuários, baias, dietas, ingredientes e previsão. O tablet passa a enxergar esses dados na nuvem.

1

Confirme a configuração

SOURCE_MODE=firebird, URL da API e código do cliente corretos.

2

Clique em “Subir agora”

Aguarde o log em linguagem simples. Em caso de erro, leia a mensagem e ajuste o .FDB ou a API.

3

Opcional: Subir + Baixar

Executa as duas operações em sequência (útil no início do dia).

Quando subir? Sempre que cadastrar ou alterar fazenda, baia, dieta, usuário ou previsão no FieldPec e quiser que o FieldTrato use a versão atualizada.
06 · Baixar

Baixar fabricação e fornecimento para o Field

O tablet FieldTrato grava fabricação e fornecimento na nuvem. O conector puxa esses registros e, com REPLAY_TO_LOCAL=1, grava direto no Firebird do FieldPec.

1

Garanta REPLAY = 1

Em Configuração, escolha 1 — gravar no Firebird e salve.

2

Baixe os dados

Em Subir / Baixar → Baixar agora, ou em Acompanhar → Enviar para o Field.

3

Confira no FieldPec

Fabricação e insumos entram como novos registros; fornecimento atualiza o realizado nas previsões existentes (FORNECIMENTO_CONF).

Atenção no fornecimento O conector só atualiza previsões que já existem no Field. Se a baia/trato do dia não tiver previsão cadastrada, o item pode falhar no log até a previsão existir no banco.
07 · Acompanhar

Acompanhar operações

Use esta aba para ver o que o tablet já enviou à nuvem e o que já foi baixado para o Field.

StatusSignificado
Pendente Tablet já enviou para a nuvem; ainda não foi gravado no Field.
Já no Field Baixado com REPLAY=1 (gravação no Firebird + confirmação na nuvem).
Atalho do dia a dia Abra Acompanhar → filtre Pendentes → Enviar para o Field → Atualizar.
08 · Checklist

Checklist rápido

  • Instalador executado como Administrador; serviço FieldPecOnlineConnector em execução
  • Painel abre em http://127.0.0.1:3080
  • CLOUD_API_URL e CLIENT_CODE preenchidos e salvos
  • FB_DATABASE aponta para o .FDB correto; SOURCE_MODE=firebird
  • REPLAY_TO_LOCAL=1 se for gravar fab/forn no Field
  • “Testar conexões” OK
  • Subiu cadastros/previsão pelo menos uma vez
  • FieldTrato no tablet com o mesmo código de cliente e API
09 · Suporte

Problemas comuns

SintomaO que verificar
Painel não abre Serviço Windows FieldPecOnlineConnector está rodando? Porta 3080 livre? Reinicie o serviço.
Erro no Firebird Caminho do .FDB, senha SYSDBA, Firebird Server ativo, permissão de leitura/escrita no arquivo.
Erro na API / código URL e porta da API, internet do PC, CLIENT_CODE cadastrado no administrador da nuvem.
Baixar não grava no Field Confirme REPLAY_TO_LOCAL=1, salve e baixe de novo. Veja o log e a aba Acompanhar.
Fornecimento falha Existe previsão (FORNECIMENTO_CONF) para aquela baia/trato/data no Field?
Precisa de ajuda? Envie à RS Sistemas: print da aba Status ou do log em Subir/Baixar, código do cliente e horário aproximado da tentativa.
